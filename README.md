## 🌸 ゲーム概要
「油滴 - YUTEKI -」は、水面に浮かぶ色鮮やかな油滴をお箸で伸ばし、ちぎり、くっつける、表面張力と流体シミュレーションを融合したマインドフルネス・パズルゲームです。

水底に揺らめく光のコースティクス（水面光）、瑞々しい油の光沢、心地よい水音（Web Audio API）とともに、心安らぐひとときをお楽しみください。

---

## 🥢 基本ルールと遊び方
1. **調和・結合 (Harmony)**:
   - 同じ色の油滴同士はお箸で引っ張って近づけると、表面張力で「ぷるん」と引き合い1つに結合します。
   - 水面上のすべての同色油滴を1つずつにまとめ（各色1滴ずつの調和状態）、ステージクリアを目指します。
2. **反発 (Repulsion)**:
   - 異なる色の油滴同士は水面上で反発し、混ざり合うことはありません。
3. **ちぎり・伸縮 (Tension)**:
   - お箸で油滴の端をビヨーンと引っ張って伸ばせます。離すと反動で元の形に戻ります。
   - 強く引っ張りすぎると、表面張力の限界を超えて「ぷちっ」と2つにちぎれます。
4. **解放ボーナスステージ (Splash Bonus)**:
   - **10ステージごと**に巨大な油滴を思いっきりかき混ぜて粉砕するボーナスステージが発生します。
   - 放っておくと表面張力で再びくっつこうとする油滴を、素早いお箸さばきでいかに細かく分裂させ続けられるかを競います。
   - 右上の「かき混ぜたい」ボタンを押せば、いつでも気分転換にかき混ぜモードを楽しめます。

## ✨ 主な機能と特徴

### 1. スコアシステム & 連鎖調和 (Sync Harmony)
- **クリアボーナス**: ステージクリア時に基本得点（1,000点 ＋ レベル×200点）を獲得。
- **連鎖調和ボーナス**: 他の色をお箸で操作している間に、別の色同士が自発的・連鎖的に合体した場合、通常合体（+50点）の5倍である **+250点（連鎖調和! ✨）** の高得点を獲得できます。
- **無限稼ぎ防止**: 油滴をちぎった（分裂させた）場合は **-60点** のペナルティが入るため、分裂と結合を繰り返すだけの不正スコア稼ぎはできません。

### 2. 色ごとの多骨格物理演算 & 非真円性 (リアルな油の挙動)
- **色ごとの骨格数**:
  - 琥珀 (Amber): 2点骨格（伝統的な水滴・ピーナッツ型）
  - 紅梅 (Rose): 3点骨格（三叉・三つ葉アメーバ）
  - 翡翠 (Emerald): 4点骨格（四ツ葉・十字型）
  - 瑠璃 (Cyan): 5点骨格（五葉星型ブロブ）
  - 藤紫 (Violet): 6点骨格（六角・複雑な粘性リング）
  - 蜜柑 (Orange) / 若葉 (Lime): 4〜5点骨格（有機的アメーバ）
- **環境に応じた歪みと丸まり**:
  - 他の色の油滴が近くにある（邪魔している）間は、斥力や外圧によって押しつぶされたいびつな形を維持します。
  - 周囲に邪魔する油滴がなく静かな状態が続くと、微弱な表面張力により**時間をかけて徐々に滑らかな丸へと還っていきます**。

### 3. スマートフォン完全対応
- 上部HUDが油滴と被らないよう、実際のヘッダー高さに基づきプレイ領域（物理反発バウンダリ）を動的に計算。
- ノッチやダイナミックアイランド等のセーフエリア（`env(safe-area-inset-top)`）にも最適化。
