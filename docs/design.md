# 油滴 - YUTEKI - 詳細設計書

## 1. 概要とコンセプト
「油滴 - YUTEKI -」は、水面に浮かぶ色とりどりの油滴をお箸で伸ばし、ちぎり、くっつける、表面張力と流体シミュレーションを融合したマインドフルネス・パズルゲームです。

### 基本ルール
- **同色融合**: 同じ色の油滴同士は表面張力により引き合い、結合して1つにまとまります。
- **異色反発**: 異なる色の油滴同士は水面上で反発し、混ざり合うことはありません。
- **ステージクリア**: 水面上の同色油滴をすべて1つにまとめ、各色1滴ずつ（調和状態）にするとクリアとなります。
- **解放ボーナス**: 10ステージごとに、巨大な油滴を思いっきり箸でかき混ぜて砕くボーナスステージが発生します。

## 2. 改善・拡張仕様

### 2.1 UI / スマホ表示最適化
- **課題**: スマートフォン等でプレイする際、画面上部のHUD（レベル表示、色インジケーター、操作ボタン等）がゲーム領域（油滴の移動可能範囲）にはみ出し、被ってしまう問題。
- **設計方針**:
  1. 上部セーフエリア（`env(safe-area-inset-top)`）およびレスポンシブデザイン（Tailwind CSS）を強化。
  2. ゲーム内境界計算（`getPlayBounds()`）をHUDの実際の描画高さ（`hud.offsetHeight`）と安全マージン（+16px〜24px）に基づいて動的に計算。
  3. 油滴の初期生成位置および画面端の物理反発バウンダリをHUDの下端より完全に下側に収めることで、スマホ縦画面・横画面問わず絶対に油滴がHUDに重ならない安全領域を確保。

### 2.2 進行バランス・難易度調整
- **ボーナスステージ頻度**:
  - 従来: 3ステージ毎
  - 改定: **10ステージ毎**（Lv10, Lv20, Lv30...）
- **緩やかなレベルアップ（難易度曲線）**:
  - 色の追加ペースを緩和（初期2色、Lv4で3色、Lv7で4色、Lv10でボーナス、Lv11で5色、Lv15で6色、Lv19で7色）。
  - 1色あたりの油滴数も序盤は3滴、中盤以降も最大4〜5滴と緩やかに上昇させ、リラックスしたプレイ体験を保つ。

### 2.3 スコアシステム
- **基本得点**:
  - ステージクリアボーナス: `1000 + (level * 200)` 点
- **連鎖調和（Sync Harmony）ボーナス**:
  - プレイヤーがお箸で油滴をドラッグ操作している最中に、操作していない他の同色油滴（例: 赤を動かしているときに黄色同士）が慣性や水流で自発的・連鎖的に合体した場合、通常合体（+50点）の5倍である **+250点 × 連鎖コンボ数** を付与。
- **無限スコア稼ぎ防止（分裂ペナルティ）**:
  - 油滴がちぎれた（分裂した）場合は **-60点**（スコアが0未満にはならない下限ガード付き）。
  - 合体（+50点）と分裂（-60点）の差分により、意図的に分裂と結合を繰り返す行為はスコアが減少するため、無限増殖を防止。
- **ボーナスステージでのスコア**:
  - 粉砕ごとに +30点。制限時間内に目標個数を達成した場合は `粉砕個数 × 50点` の達成ボーナス。
- **UI表示**:
  - HUDに「Score」「High Score」を表示。
  - 得点加算・減算時に水面上に心地よい浮遊テキスト（ポップアップアニメーション）を表示。

### 2.4 ボーナスステージでの合体と分裂のゲーム性
- ボーナスステージ中でも、同色油滴が接近・接触すると表面張力により結合する挙動を有効化。
- 油滴は自然に元の塊に戻ろうとする性質を持つため、プレイヤーはお箸で絶え間なく素早くかき混ぜて「いかに結合を阻み、細かく分裂させた状態を維持・増加させるか」という動的でスリリングな操作を楽しむことができる。

### 2.5 多骨格ノード物理と非真円性（粘弾性・アメーバ挙動）
- **色別の骨格ノード数**:
  - 油滴の色や特性に応じて、内部骨格を2点〜最大6点の連結ノードシステムへと拡張。
    - 琥珀 (Amber): 2ノード（伝統的な水滴・線分型）
    - 紅梅 (Rose): 3ノード（Y字・三又の有機的形状）
    - 翡翠 (Emerald): 4ノード（十字・四葉の弾性体）
    - 瑠璃 (Cyan): 5ノード（五葉・星型のアメーバ体）
    - 藤紫 (Violet): 6ノード（六角・複雑な粘性リング）
    - 蜜柑 (Orange): 4ノード（非対称楕円体）
    - 若葉 (Lime): 5ノード（多葉クローバー型）
- **非真円性（まん丸にならない条件と徐々に丸くなる条件）**:
  - 現実の油滴は、粘性や周囲の不純物・外圧によって必ずしも真円にはならず、歪んだ形状を保つ。
  - **丸くならない条件**:
    1. 周囲に他の油滴（特に異色）が存在し、斥力や干渉を受けているとき。
    2. 油滴の面積が大きい場合（内部粘弾性が高く、形状復元が遅い）。
    3. 外力（お箸による引っ張り・かき混ぜ）直後で歪みエネルギーが残っているとき。
  - **徐々に丸くなる条件**:
    1. 周囲に干渉する油滴がなく、水面が静止している状態が維持されると、微弱な表面張力によって数十秒かけてじわじわと真円に収束する。
- **描画システム**:
  - 各骨格ノードの外周をCatmull-Rom閉曲線スプライン補間し、光沢・屈折ハイライト・落影を多骨格に対応して美しくレンダリング。
